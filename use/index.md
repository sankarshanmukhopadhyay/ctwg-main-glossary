# Use TIG

TIG is designed to be consumed, not merely read. Choose the path that matches how you want to use the vocabulary.

## Use a bounded vocabulary

Vocabulary profiles select stable TIG concepts for a particular implementation or governance domain without redefining them.

[Explore vocabulary profiles]({{ '/profiles/' | relative_url }})

## Integrate machine-readable semantics

Consume canonical JSON, JSON-LD, SKOS-compatible Turtle, manifests, inventories, and compatibility bundles.

[View machine-readable artifacts]({{ '/artifacts/' | relative_url }})

## Adopt TIG downstream

Use stable concept IDs, pin releases where reproducibility matters, and record the profile or subset used by your project.

[Read downstream consumption guidance]({{ '/governance/downstream-consumption/' | relative_url }})

## Moving from v1

Version 2 separates concepts from their designations and changes the canonical artifact names.

[Read the v2 migration guide]({{ '/migration-v2/' | relative_url }})
