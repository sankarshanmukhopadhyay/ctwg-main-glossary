# Legacy source corpus

The files in this directory are retained as provenance evidence from the project's Trust over IP lineage and to support `source_file` references in migrated concept artifacts.

They are **not** the authoritative v2 publication source.

For Trust Infrastructure Glossary v2:

- authoritative concept source: `glossary/terms/*.yaml`
- validation contract: `schemas/`
- generated publication: `_terms/`, `generated/`, and the Jekyll site
- semantic and provenance governance: `governance/`

Historical ToIP wording, authorship, and references in this directory are intentionally preserved for attribution and auditability.
